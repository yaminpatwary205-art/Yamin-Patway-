# রিভিশন অ্যালার্ম (Revision Alarm) — বাংলা গাইড

## ১. অ্যাপ ইনস্টল ও ফোনে সেটআপ
1. AI Studio থেকে APK তৈরি করে আপনার অ্যান্ড্রয়েড ফোনে ইনস্টল করুন।
2. প্রথমবার খোলার পর **সেটিংস > নোটিফিকেশন চালু** এবং **সঠিক অ্যালার্ম অনুমতি** অন করে দিন যাতে ব্যাকগ্রাউন্ডেও রিভিশন অ্যালার্ম ঠিক সময়ে বাজে।
3. চাইলে **অ্যালার্ম মোড** চালু রাখুন—এতে স্ক্রিন জেগে থাকবে এবং প্রতিটি নির্ধারিত সময়ে স্বয়ংক্রিয়ভাবে ফুল-স্ক্রিন পপ-আপ খুলবে।
4. অ্যাপ বন্ধ থাকলেও ক্যালেন্ডার অ্যালার্ট পেতে **সেটিংস > ক্যালেন্ডার রিমাইন্ডার এক্সপোর্ট (.ics)** ব্যবহার করে Google Calendar-এ রিমাইন্ডার যুক্ত করুন।

## ২. Firebase সেটআপ (Google Login, Firestore এবং Gemini AI)
- এই অ্যাপে Firebase Firestore, Google Sign-In এবং Firebase AI Logic (App Check সহ) ইতোমধ্যে কনফিগার করা হয়েছে (`app/google-services.json`, `app/src/main/res/values/firebase_applet_config.xml`, `firestore.rules`)।
- নিজস্ব প্রোজেক্টে ম্যানুয়ালি যুক্ত করতে চাইলে:
  1. Firebase Console-এ একটি প্রোজেক্ট তৈরি করুন।
  2. **Authentication > Sign-in method > Google** চালু করুন এবং অ্যাপের SHA-1/SHA-256 যুক্ত করুন।
  3. **Firestore Database** তৈরি করুন এবং `firestore.rules` ফাইলটি রুলস ট্যাবে পেস্ট করে Publish করুন।
  4. **Firebase AI Logic** এবং **App Check** চালু করুন।
  5. কোনো ক্লায়েন্ট-সাইড API Key ছাড়াই অ্যাপটি সরাসরি ইংরেজি লাইন ও শব্দ বাংলায় অনুবাদ করবে।
